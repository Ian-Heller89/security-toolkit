# security-toolkit

Red, blue, and purple team tools built in Python, Go, and Rust.

## Structure
- `red-team/`: offensive tooling (scanners, enumeration)
- `blue-team/`: defensive tooling (log analysis, detection)
- `purple-team/`: attack/detect harnesses mapped to MITRE ATT&CK
- `notes/`: sanitized study notes

## Roadmap
- [ ] Async port scanner (red-team)
- [ ] SSH brute-force log detector (blue-team)
- [ ] Purple-team harness
- [ ] AWS S3 misconfiguration auditor
